Konark Heritage Game

Controls:
SPACE / ArrowUp / W = Jump
ArrowDown / S = Slide
P = Pause
ESC = Pause / Resume
ESC pause menu -> QUIT GAME returns to title
R = Restart after Game Over

Animation was tuned for smoother running: 8 run frames at about 16 FPS with state-aware animation timing.

JUMP FIX: SPACE, ArrowUp, W, or the on-screen ▲ button. The player sprite now follows the physics Y position, so the jump is visibly rendered.

Run sprites were cleaned using border-connected background removal to keep white clothing intact.
