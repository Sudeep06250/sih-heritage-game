# The Sea Whisperer (Operation Sea Whisper / Rushikulya Beach Quest)

An interactive environmental and wildlife conservation quest in Odisha focusing on Olive Ridley sea turtle protection across four interactive missions.

## Folder Structure
- sea-whisperer/: Contains all game missions, logic, ocean audio, and beach/turtle assets.
  - operation_sea_whisper.html / index.html: Main game webpage (Missions 01 & 02).
  - mission3.html: Interactive sub-missions (Missions 03 & 04).
  - Ocean_sound.mp3: Ocean ambient score.
  - ssets/: Image assets for Rushikulya beach, turtles, conservation items, and night scenes.
- index.html: Root launcher redirecting to the game.

## How to Play
Open sea-whisperer/index.html or index.html directly in any web browser.
