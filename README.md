# The Sound Identifier (Dhwani: Echoes of Odisha)

An interactive heritage audio quest game where players listen to traditional sounds and musical instruments of Odisha and identify them.

## Folder Structure
- sound-identifier/: Contains all game code, UI, audio, and asset files.
  - The_sound_Identifier.html / index.html: Main game webpage.
  - Temple_music.mp3: Ambient background score.
  - ssets/audio/: Sound clips for traditional instruments (Bell, Flute, Mardala, Ocean, Odishi, Sankha).
  - ssets/: Image assets for the instruments and temple themes.
- index.html: Root launcher redirecting to the game.

## How to Play
Open sound-identifier/index.html or index.html directly in any web browser.
